# 🍔 Hamburger Game

PythonとFletを用いて制作したハンバーガーゲームです。

## 📌 概要

授業で扱ったボール投げゲームをもとに、
食材を投げてハンバーガーを完成させるゲームを制作しました。

画面に表示される「お題のハンバーガー」を確認し、
必要な食材を正しくウェイトレスに投げてキャッチしてもらうことで、
ハンバーガーを完成させます。

## 🎮 遊び方

1. 画面左上のお題を確認する
2. 表示された食材をドラッグする
3. 投げる方向と強さを調整して離す
4. ウェイトレスが正しい食材をキャッチすると成功
5. 必要な食材をすべて集めるとクリア
6. 間違った食材を投げたり、正しい食材を落としたりすると失敗

10回失敗するとゲームオーバーになります。

## 🛠 使用技術

- Python
- Flet
- OpenCV

## 💡 主な機能

### ① ハンバーガーのお題表示

複数のハンバーガーのレシピを登録し、
ラウンドごとに異なるお題を表示します。

### ② 食材のランダム生成

正しい食材だけでなく、間違った食材もランダムに出現するようにしました。

プレイヤーはお題を確認し、
必要な食材を判断して投げる必要があります。

### ③ ドラッグ＆ドロップ操作

食材をマウスでドラッグして移動し、
離した方向と位置から投げる速度を計算しています。

### ④ 物理シミュレーション

重力と空気抵抗を考慮して、
投げた食材が放物線を描いて飛ぶように実装しました。

速度・位置・時間を計算しながら、
食材の動きをリアルタイムに更新しています。

### ⑤ キャッチ判定

食材とウェイトレスの手との距離を計算し、
一定の距離以内に入るとキャッチ成功と判定します。

正しい食材の場合はハンバーガーに積み重ね、
間違った食材の場合は失敗として処理します。

### ⑥ ゲームオーバー・クリア判定

10回失敗するとゲームオーバー、
レシピに必要な食材をすべて集めるとクリアとなります。

本制作を通して、Fletを用いたGUIアプリケーションの開発や、
ユーザーの操作に応じて画面を更新する処理について学びました。

また、重力・速度・空気抵抗などを利用した物理シミュレーションを実装することで、
時間経過に応じてオブジェクトの状態を変化させる処理への理解を深めました。

さらに、ゲームの状態管理や当たり判定、エラー発生時の処理など、
複数の機能を組み合わせて一つのアプリケーションを構築する経験を得ました。
